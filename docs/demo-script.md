# Demo Script

1. Show the home console and explain AlphaTrace as an ERC-8004 identity plus ERC-8183 job worker.
2. Open Agent Profile and point to address, identity ID, metadata URI, and capabilities.
3. Create a WCT token flow research job.
4. Use Demo sync for the local run, or Create on Arc after contract config is ready.
5. Open the Job detail page.
6. Click Run Agent.
7. Show the generated report, scores, evidence list, recommendation, and verified hash.
8. Explain that the full report stays off-chain while the hash is submitted as the deliverable proof.
9. Submit feedback to show the reputation loop.
